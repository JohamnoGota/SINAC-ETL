# SINAC - ETL
An end-to-end, serverless and scalable ETL pipeline for integrating, analyzing and visualizing the Mexican National Birth Information Subsystem (SINAC) over a period from 2008 to 2024, using AWS serverless infrastrucutere, Apache spark and Terraform.

## Objectives
The purpose of this repository is the easy analysis of the SINAC database via a complete integration of the historical data and a user ready final layer that is ready for visualization, reasearch questions and bussines inteligence (BI) for over 32 Million registers spread over 3 historical periods.
